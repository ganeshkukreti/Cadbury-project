🍫 I built a full-stack Chocolate Company E-Commerce + Admin System, with Power BI-ready data analytics! 📊

I've been working on a project for the past few days and I'm excited to finally share it: Cadbury Premium, a complete ordering website designed to run on a screen at a shopkeeper's outlet. 🚀

💡 The Idea
In a real retail outlet, orders can come from the counter or online. I wanted one system that captures every order in one place, so the data can later be analyzed in Power BI to drive real business decisions.

🛍️ Customer Side (Cadbury Premium)
✅ 12 premium products with category filters (Dark, Milk, Gift Boxes, Truffles, Seasonal)
✅ Live search and sorting
✅ Quick View popup with ratings, discounts, and pricing
✅ Add to Cart and a smooth checkout flow
✅ Premium dark + gold UI design

⚙️ Admin Panel (CadburyAdmin)
✅ Dashboard with Total Revenue, Orders, Products, and Customers
✅ Last 7 Days Revenue chart
✅ Add / Edit / Remove products
✅ Orders and Customers management
✅ One-click Excel export

📈 Power BI Analysis
By connecting the exported Excel data to Power BI, I can uncover insights like:
🔹 Best-selling products and categories
🔹 Daily and weekly revenue trends
🔹 Peak order hours
🔹 Repeat customers
🔹 Counter vs Online orders

🛠️ Tech Stack
HTML, CSS, JavaScript | Excel (SheetJS) | Power BI

📚 Key Learnings
This project taught me how to combine UI/UX design, state management, data export, and business analytics in a single build. My biggest takeaway: a great product isn't just code, it's also about using data to make smarter decisions. 💭
